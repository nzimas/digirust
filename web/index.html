Modified firmware for the Elektron Digitone II.

Patch, kit, phrase and pattern generation for IDM, rhythmic noise / power noise, and electroacoustic music.

Browser patcher Firmware manual

Required input: official Digitone II OS 1.12. Processing is local. No firmware upload or automatic installation.

Functions

Patch
Selected track sound.
Kit
All 16 track sounds.
Phrase
Selected track sequence.
Pattern
Complete pattern, tempo and compressor settings.

Also includes Control All macros, live note latch and Perform Kit restoration. Controls and parameters.
