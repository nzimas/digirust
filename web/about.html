Project information

Unofficial firmware modification for the Elektron Digitone II.

Musical direction

The generators target IDM, rhythmic noise, industrial, electroacoustic and acousmatic music. Conventional groovebox workflows and mainstream beatmaking are outside the project's scope.

Developer hardware report

The developer reports that DigiRust modified firmware has been thoroughly tested on a real Elektron Digitone II and is currently running on that instrument without any observed issues. This report was supplied on 12 October 2026.

This is a factual report of experience on that instrument. It is not encouragement to install, an endorsement, a safety guarantee or a prediction of results on another instrument.

Verification

The browser patcher checks the exact official input, pinned patch resources, stock and modified MAIN hashes, compression round-trip, protected section bytes and the complete output SHA-256. It must produce the same DigiRust image as the macOS patcher.

The firmware's recorded development tests include host/CPU parity, stock codecs, menu and control checks, and exact-package emulated boot and front-panel execution. These checks do not establish every possible hardware or musical outcome. Read the evidence and limits ↗.

Privacy

The patcher processes the selected file in browser memory. It does not upload firmware, connect to instruments, request MIDI access or send telemetry. GitHub Pages serves the site and its patch resources. The demo connects to YouTube only when you press play.

Versions

The browser app creates DigiRust from official OS 1.12. Patcher versions are separate from firmware revisions; the instrument's internal OS remains 1.12. The existing DigiRust 1.2.0 macOS app is also available.
